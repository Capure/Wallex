# Wallex

An open-source alternative to [Wallpaper Engine](https://www.wallpaperengine.io/en).

Wallex aims to be mostly compatible with the Wallpaper Engine API.

In order for the wallpaper to work with wallex it must be of type web or video.

The current version of wallex only supports offers basic support.

For more feature complete experience refer to an older versions of wallex (Windows only).

### Support Matrix

| Feature                    | Windows | MacOS | Linux |
| ---------                  | ------- | ----- | ----- |
| Web - Basic Support        | Yes     | Yes   | No    |
| Web - Mouse Events         | No      | No    | No    |
| Web - Sound Support        | No      | No    | No    |
| Web - CPU Saver            | No      | No    | No    |
| Video - Basic Support      | No      | Yes   | No    |
| Native 3D - Basic Support  | No      | No    | No    |
